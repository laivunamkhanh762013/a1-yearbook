# Kỷ yếu A1 - Project Instructions

Welcome to the **Kỷ yếu A1** digital yearbook project. This project is managed using a **Get Stuff Done (GSD)** workflow.

## Project Structure
- `index.html`: Entry gate (Passcode: 2013).
- `main.html`: Primary dashboard (Members, Countdown, Voting).
- `firebase.js`: Firebase integration for real-time features.
- `.planning/`: GSD workflow artifacts (Roadmap, Requirements, Intel).

## GSD Workflow
This project follows the Research -> Strategy -> Execution lifecycle.
- **Intelligence**: Found in `.planning/intel/`.
- **Roadmap**: Found in `.planning/ROADMAP.md`.
- **Requirements**: Found in `.planning/REQUIREMENTS.md`.
