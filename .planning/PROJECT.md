# Project: Kỷ yếu A1

## Core Value
A digital yearbook for class 7A1 THCS Chu Văn An - Thanh Trì, preserving memories through an interactive web experience.

## Vision
To provide a central, secure, and engaging platform for students to revisit class memories, vote on polls, and stay connected.

## Constraints
- **Platform:** Static web application.
- **Backend:** Firebase (Realtime Database) for dynamic content.
- **Access Control:** Simple passcode protection.
- **Maintenance:** Must be easy for non-developers to update content (eventually).

## Stakeholders
- Students of class 7A1.
- Teachers and parents (as viewers).
