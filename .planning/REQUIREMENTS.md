# Requirements: Kỷ yếu A1

## v1 Requirements

### Stabilization (STAB)
- **STAB-01**: Clean up mixed environment (separate Cursor/VSCode application files from source code).
- **STAB-02**: Organize project structure (move source to `src/`, assets to `assets/`).
- **STAB-03**: Fix broken paths and ensure the site runs correctly in the new structure.

### Feature Enhancement (FEAT)
- **FEAT-01**: Improve UI/UX (consistent styling, responsive layout for mobile, better navigation).
- **FEAT-02**: Enhance interactivity (refined voting system, countdown timer improvements).
- **FEAT-03**: Implement/Refine real-time chat/guestbook feature.

### Data Management (DATA)
- **DATA-01**: Externalize student data (move from hardcoded array in `main.html` to `data/members.json`).
- **DATA-02**: Optimize asset loading (compress images, use modern formats like WebP).

### Deployment (DEPL)
- **DEPL-01**: Final cross-browser and cross-device testing.
- **DEPL-02**: Deploy to hosting (Firebase Hosting suggested).
